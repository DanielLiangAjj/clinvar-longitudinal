# ClinVar Longitudinal Reclassification Analysis (2012–2025)

Companion code, data, figures, and an **interactive web companion** for the manuscript:

> **Temporal Analysis of Clinical Variant Reclassification (2012–2025)** — submitted to *Genome Medicine*.

A longitudinal reprocessing of **3,678,303 variants** across **148 monthly ClinVar XML snapshots**
(November 2012 – July 2025), designed to distinguish genuine clinical reinterpretation from
artifacts of database/schema evolution.

## 🔎 Interactive companion

**➡ https://danielliangajj.github.io/clinvar-longitudinal/**

A self-contained, reviewer-friendly site that visualizes every analysis interactively (hover,
zoom, toggle series): database growth, the classification landscape, clinically-stratified
reclassification, censored time-to-event (Kaplan–Meier) curves, mechanism attribution, effect
sizes and confounder-adjusted odds ratios, interrupted time-series, disease-domain variability,
inter-submitter concordance, citation-evidence filtering, schema evolution, and the (anonymized)
submitter landscape.

## Key findings

- **9.3%** of variants underwent ≥1 change in aggregate classification category, but only **0.68%**
  (25,105 variants) ever crossed the clinical actionability boundary (a *medically significant*
  change).
- Censored **Kaplan–Meier** cumulative incidence of first reclassification: **2.5% at 1 yr, 15.5% at
  5 yr, 30.9% at 10 yr** (median never reached).
- Reclassification rates are elevated in cancer genes and higher-prevalence Mendelian disease genes;
  effects are **attenuated but survive multivariable adjustment** (cancer adjusted OR 1.48).
- PubMed "evidence depth" is dominated by two assertion-method papers (SHERLOC 84%, ACMG/AMP 2015
  25%); after filtering, only **~12%** of variants carry a genuine variant-specific citation.
- **2.6%** of all reclassification events are attributable to the RCV→VCV schema transition.

## Reproducing the analysis

Requires Python 3.10+ (`pip install -r requirements.txt`: pandas, numpy, scipy, statsmodels,
matplotlib, lxml).

The raw inputs are the public NCBI ClinVar monthly XML releases
(<https://ftp.ncbi.nlm.nih.gov/pub/clinvar/xml/>). The multi-GB intermediate tables (per-variant
`summary`, `classification_history`, per-snapshot checkpoints) are **not redistributed here** — they
are regenerated by the pipeline:

```bash
python scripts/clinvar_ftp_only_v5.py --output-dir ./data     # download + parse all snapshots
python scripts/clinvar_reclassification_driver.py             # mechanism attribution
python scripts/clinvar_domain_analyzer.py                     # disease-domain analysis
# … see scripts/ for the full set
python revision_analyses/01_survival_analysis.py              # censored time-to-event
python revision_analyses/05_multivariable_baseline.py         # adjusted logistic regression
python revision_analyses/06_its.py                            # interrupted time-series
python revision_analyses/11_citation_filtering.py             # guideline-citation filtering
```

### Added in v1.1.0 (second and third revision rounds)

```bash
python revision_analyses/12_origin_sensitivity.py             # allele-origin sensitivity (somatic exclusion)
python revision_analyses/13_cgc_sensitivity.py                # hereditary-cancer gene-set sensitivity
python revision_analyses/19_cosmic_germline_sensitivity.py    # COSMIC germline gene-set sensitivity
python revision_analyses/26_two_reviewer_analysis.py          # two-reviewer validation of mechanism attribution
python revision_analyses/28_citation_filtered_r3.py           # variant-specific citation counts + figures
python revision_analyses/29_km_r3.py                          # competing-risks cumulative incidence + sensitivities
python revision_analyses/30_cox_r3.py                         # era-stratified Cox models (replaces logistic)
python revision_analyses/31_its_r3.py                         # flow-based interrupted time-series outcomes
python revision_analyses/17_rebuild_figure5_native.py         # Figure 5
python revision_analyses/r4_figures.py                        # Figures 6, 8, 9, 11-15 and Additional file 1 Fig. S3 (final)
python revision_analyses/r4_suppfig_review_status.py         # Additional file 1 Fig. S4
```

`revision_analyses/outputs/mechanism_validation_labels_two_reviewers.csv` holds the per-event labels
from the blinded two-reviewer validation (48 events; heuristic label, each reviewer's label and
confidence). Reviewer free-text notes and record-level submitter details are not redistributed.
Final figures are in `figures/revision_2026_10/`.

## Data availability & anonymization

- **Source data:** public NCBI ClinVar (public domain).
- **Archived release:** Zenodo DOI `10.5281/zenodo.XXXXXXX` *(to be minted on acceptance)*.
- **Laboratory anonymization:** consistent with the manuscript, all ClinVar submitter identities are
  replaced with coded labels (**Laboratory A, B, C…**, by submission rank). No real laboratory name
  appears in the published data, figures, or interactive site. Public reference resources (OMIM,
  ClinGen, GeneReviews, All of Us) are named as in the manuscript.
